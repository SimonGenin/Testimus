# PARITY.md — Xray Editor → Testimus, capability by capability

Goal (2026-11-02): every capability a user can see, do or edit in Xray Editor (`D:\Projects\XrayEditor`) exists in
Testimus — same capability, not necessarily the same look. Built from three read-only audits over all of Xray Editor's
`src/` and `src-tauri/` (editor/sidebar/shell; Claude/settings/core; a verification of every gap found), each row
checked against the Testimus code and its tests. "Design" in a note means Testimus reaches the same capability another
way, on purpose (SPEC wins).

The « Testimus » column names where the capability lives today (after the grand nettoyage, 2026-11-04): screen parts
under `src/ui/screens/`, kit components under `src/ui/components/ui/`, the data layer under `src/ui/lib/data/`, the
core under `src/core/`. The « Test » column cites the tests that drive the capability and assert its outcome, as
`path › « part of the full test name »` (describe › it), several separated by « ; ». Unit tests are cited by their
path from the repository root, Playwright specs by their path under `tests/e2e/` (the form Playwright reports).
`node .build/v3/parity-proof.mjs <vitest.json> <playwright.json>` checks that every cited test exists and passes.
